# EcoSupporthelp

A web page with a knowledge base on Ecotime and how to support common issues.

**What's in it**

- How a clocking becomes pay, step by step
- Support desk troubleshooter for shift, break, hours and error calls, with call questions and a ticket template
- Breaks and clockings, setup order, shifts and rosters, overtime authorisation
- Daily payroll routine, error fixes, leave and a searchable glossary

It is a single static page (`index.html`) with no build step. Open it in a browser, or view it on GitHub Pages.

Based on the public Eco Time documentation at docs.eco-time.com. Items tagged "Support tip" are general time and attendance practice rather than quotes from the docs. This is an unofficial learning aid and is not affiliated with Eco Time.
